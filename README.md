# Dotadle

Браузерная игра: угадай героя Dota 2 по признакам.

- **Герой дня** — один герой для всех, меняется в полночь; статистика и серии побед.
- **Бесконечный** — случайный герой каждую игру.

Признаки: пол, раса, основной атрибут, тип атаки, роли, дальность атаки, скорость, количество ног.
Поиск понимает английские и русские имена, а также сленг (сф, пудж, квинка, бара…).

## Запуск

Сборка не нужна — просто откройте `index.html` в браузере или выложите файлы на любой статический хостинг (например, GitHub Pages).

## Файлы

- `index.html` — игра (вёрстка, стили, логика).
- `extraData.js` — данные о героях (`window.HEROES`). Характеристики взяты из [odota/dotaconstants](https://github.com/odota/dotaconstants), пол/раса/русские имена добавлены вручную.
